# Crypto Explorer 2

A simple command-line tool that fetches live cryptocurrency prices using the CoinGecko API.

## Features
- Get real-time prices for BTC, ETH, and more
- Lightweight and easy to use

## Quick Start
```bash
pip install -r requirements.txt
python src/cli.py --symbol bitcoin
## Example Output

```bash
$ python src/cli.py --symbol bitcoin
bitcoin price (USD): 110000
